# BFHL Project

This project is a web application built using JavaScript, HTML, and CSS, with a Node.js backend.

The project helped me explore frontend development, backend integration, and how different parts of a web application work together.

## About the Project

The application contains a frontend interface and a backend server. The frontend handles the user interface, while the backend manages the server-side functionality.

The project structure makes it possible to develop and test the application locally.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
